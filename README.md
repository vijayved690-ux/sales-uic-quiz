# UIC MIS BOT - Render Deployment

## Run Locally
npm install
npm start

## Deploy on Render
1. Upload all files to GitHub
2. Connect repo to Render
3. Create Web Service
4. Build Command:
npm install

5. Start Command:
npm start

## Required Files
- mis-bot.js
- package.json
- google-creds.json
- render.yaml

## Configure
Replace:
- MANAGER_PHONE
- SHEET_ID
- Buddy phone numbers
